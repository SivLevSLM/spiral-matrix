# spiral-matrix
Асинхронная библиотека: скачивает квадратную матрицу NxN по URL и возвращает
её обход по спирали (против часовой стрелки, с левого верхнего угла).

Задание: https://github.com/avito-tech/python-trainee-assignment

## Что сделано
- get_matrix(url) через aiohttp
- разбор таблицы, обход матриц любого размера NxN
- ошибки сервера и сети (5xx, таймаут, отказ соединения) -> MatrixFetchError
- неверный формат (не числа, не квадратная) -> MatrixFormatError

## Что не сделано
- повторные запросы при сбое, публикация в PyPI

## Как запустить
pip install -r requirements.txt
python -m pytest

## Как проверяли
Тесты в папке tests: матрица из задания, размеры 1x1, 2x2, 3x3,
локальный сервер с ошибкой 500, таймаутом и отказом соединения.
